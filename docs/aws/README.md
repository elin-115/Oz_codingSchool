## 🔀 진행 흐름

1~4(서버 준비)와 5~6 파일 작성(레포 작업)은 동시에 진행함.

```
김지연: 1 계정 → 2 EC2 → 3 도커 설치 → 4 스왑 ─┐
팀원:   5 이미지 빌드·푸시, 6 파일 작성 ─────────┴─▶ 6 복사 → 7 실행·QA → 8 정리
```

## ⚠️ 주의

- `.pem` 키, `.prod.env`, Docker Hub PAT, AWS 비밀번호·액세스 키는 절대 커밋하지 않음
- 과제가 끝나면 8단계 리소스 정리를 반드시 진행함
