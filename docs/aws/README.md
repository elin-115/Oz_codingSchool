## 🔀 진행 방식

1. 김지연이 0~8단계를 먼저 직접 진행하고, 단계마다 어떻게 했는지·막힌 점을 문서로 정리함
2. 정리한 문서를 팀원들에게 공유하고, 문서를 보며 팀원도 함께 따라 해 봄
3. 배포 주소에서 4명이 함께 QA 진행

```
김지연: 1 계정 → 2 EC2 → 3 도커 설치 → 4 스왑 → 5 빌드·푸시 → 6 파일 작성·복사 → 7 실행 → 문서 정리
                                                                                    │ 공유
팀원:                                                                  문서 보며 실습 → 7 QA → 8 정리
```

## ⚠️ 주의

- `.pem` 키, `.prod.env`, Docker Hub PAT, AWS 비밀번호·액세스 키는 절대 커밋하지 않음
- 과제가 끝나면 8단계 리소스 정리를 반드시 진행함
