# 8️⃣ AWS 리소스 정리

> AWS는 쓴 만큼 요금이 나가는 종량제라서, 과제가 끝나면 사용한 리소스를 모두 정리함

## ✅ 체크리스트

- [ ] 최종 캡처, QA 결과 문서화 완료 (정리하면 다시 볼 수 없음)
- [ ] EC2 인스턴스 **종료(Terminate)**
- [ ] EBS 볼륨이 남아 있지 않은지 확인
- [ ] 탄력적 IP를 할당했다면 **해제**
- [ ] 키 페어, 보안 그룹 삭제
- [ ] Docker Hub PAT 토큰 삭제
- [ ] 결제 대시보드(Billing)에서 예상 요금 확인
