## ⚠️ 맥에서 빌드할 때 주의

- 맥(M칩)은 ARM, EC2 t3.micro는 x86(amd64)
- 그냥 빌드하면 EC2에서 `exec format error` → `--platform linux/amd64`로 빌드해야 함
- 리눅스용 torch는 `pyproject.toml` 설정대로 CPU 전용으로 설치됨

## ✅ 진행 순서

- [ ] Docker Hub 계정 만들기, PAT 토큰 발급
- [ ] `docker-compose.yml`의 fastapi에 `image: 유저이름/저장소:태그` 추가
- [ ] amd64로 빌드 후 푸시
- [ ] 푸시 전에 이미지 안에 `.env`가 없는지 확인

```bash
docker login -u 유저이름
docker buildx build --platform linux/amd64 -f app/Dockerfile -t 유저이름/저장소:latest --push .
```
