# 4️⃣ EC2 인스턴스의 Swap Memory 설정하기

- 담당: 김지연
- 날짜:

## 🤔 왜 필요한가

- t3.micro는 RAM이 1GB뿐임
- 우리 서버는 MySQL(약 400MB) + torch와 AI 모델 3개(약 700MB 이상)를 함께 올림
- RAM이 가득 차면 OOM Killer가 컨테이너를 강제 종료함 → 디스크 일부를 메모리처럼 쓰는 스왑으로 버팀
- 대신 디스크가 RAM보다 느려서 성능이 떨어질 수 있음 (첫 AI 예측이 느릴 수 있음)

## ✅ 진행 순서

```bash
sudo fallocate -l 4G /swapfile      # 4GB 스왑 파일 생성
sudo chmod 600 /swapfile            # root만 읽고 쓰게
sudo mkswap /swapfile               # 스왑 영역으로 설정
sudo swapon /swapfile               # 스왑 켜기
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab   # 재부팅해도 유지
free -h                             # Swap 4.0G 확인
```
