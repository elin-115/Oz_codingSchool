## 💡 배운 것

- **API를 프론트 기준으로 설계하면 연결 단계가 가벼워짐.** Stage 4부터 `apis.js`의 주소·필드에 맞춰서, Stage 7에서는 프론트 코드를 고치지 않고 실행 확인만으로 끝남
- **토큰 재발급은 화면에 안 보이는 기능이라 확인 방법을 따로 만들어야 함.** 만료 토큰을 넣고 요청 순서를 기록해서 401 → refresh → 재요청 흐름을 보여줌
- **`fastapi run`은 운영 모드라 코드를 바꿔도 자동으로 다시 시작하지 않음.** 개발 중에는 `fastapi dev`, 확인·제출용 실행은 `fastapi run`
- **캡처 문서도 개인정보를 신경 써야 함.** 실제 계정 대신 캡처 전용 계정을 만들고 끝나면 지우기
